# OWNLOCAL LIVE — Static Ilkal Pilot POC

A mobile-first, fully static proof-of-concept based on the OWNLOCAL LIVE project overview. No backend, database, payment gateway, or real authentication is used.

## Run locally
Open `index.html`, or run any static web server in this directory.

## Deploy
### Vercel
Import this folder/repository as a new project. No build command is needed; publish the repository root.

### Cloudflare Pages
Connect the Git repository to Pages. Use no framework preset and publish the repository root. No build command is required.

## Important
All stores, users, riders, orders, prices, credentials and operational states are illustrative demo data. The POC does not process real payments or store personal information.
